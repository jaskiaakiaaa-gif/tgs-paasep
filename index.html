Fase 1: Pengenalan Konsep VPS & Cloud

Pemahaman perbedaan layanan hosting dan cloud computing:

Shared Hosting

Layanan hosting di mana beberapa website berbagi satu server fisik dan sumber daya (CPU, RAM, disk) yang sama. Biayanya murah dan mudah dikelola, tetapi performa dapat terpengaruh jika trafik pengguna lain sedang tinggi.

Dedicated Server

Layanan penyewaan satu server fisik secara utuh khusus untuk satu pengguna/organisasi saja. Memberikan performa maksimal, keamanan tinggi, serta kontrol penuh, namun membutuhkan biaya mahal dan keahlian teknis mendalam.

Amazon Lightsail

Layanan VPS cloud dari AWS yang dirancang untuk kemudahan penggunaan dengan paket harga bulanan tetap (bundling compute, storage, dan jaringan). Cocok untuk pemula, blog, atau aplikasi web skala kecil hingga menengah.

Amazon EC2

Layanan komputasi awan (IaaS) utama dari AWS yang menyediakan kapasitas server virtual (instance) yang sangat fleksibel dan dapat diskalakan sesuai kebutuhan. Pengguna memiliki kendali penuh atas sistem operasi, jaringan, dan keamanan.

Fase 2: Persiapan dan Provisioning Server

  • Mengaktifkan akun AWS dan login ke Management Console.
  • Memilih Region AWS (Praktik: us-east-1 / N. Virginia).
  • Memilih Amazon Machine Image (AMI): Microsoft Windows Server (atau Ubuntu 22.04 LTS sesuai modul).
  • Memilih Instance Type: t3.large (sesuai spesifikasi praktik lab).
PENTING: Manajemen Key Pair
Saat melakukan provisioning, AWS meminta pembuatan Key Pair (.pem atau .ppk) sebagai kunci autentikasi/dekripsi password administrator server.
Nama Key Pair yang saya buat: vockey (AWS Learner Lab Key Pair)

Fase 3: Jaringan, Keamanan, dan Akses Server

Tabel konfigurasi Security Group untuk mengizinkan akses ke server web:

Tipe Akses Protokol Port Range Source (Sumber) Deskripsi / Kegunaan
SSH (Linux) / RDP (Windows) TCP 22 (SSH) / 3389 (RDP) Anywhere (0.0.0.0/0) Akses remote terminal / Remote Desktop
HTTP TCP 80 Anywhere (0.0.0.0/0) Akses website tanpa enkripsi
HTTPS TCP 443 Anywhere (0.0.0.0/0) Akses website aman (SSL/TLS)
Custom TCP TCP 8080 My IP Akses panel admin khusus

Perintah lengkap mengakses server melalui SSH (jika menggunakan Ubuntu/Linux):

ssh -i "vockey.pem" ubuntu@3.81.83.137

*Catatan Praktik Windows Server: Akses dilakukan menggunakan aplikasi Remote Desktop (RDP) ke IP 3.81.83.137 dengan username Administrator.

Fase 4: Konfigurasi Sistem Operasi & Web Server

Pencocokan perintah Linux dengan fungsinya yang tepat:

1. sudo apt update → ( C )

2. sudo systemctl restart apache2 → ( D )

3. ls -la → ( A )

4. chmod 400 key.pem → ( B )

A. Menampilkan seluruh file termasuk yang tersembunyi.

B. Mengubah hak akses file menjadi read-only.

C. Memperbarui daftar paket repositori OS.

D. Memuat ulang layanan web server.

Tugas Praktik Web Server:
  1. Instal Web Server (Apache melalui XAMPP pada Windows Server).
  2. Clone/tempatkan file website pada direktori web root (C:\xampp\htdocs\).
  3. Buka IP Publik server di browser.
Alamat IP Publik Server saya: http://3.81.83.137

Fase 5: Deployment Aplikasi dan Domain

Konfigurasi DNS Record untuk mengarahkan nama domain ke IP Publik server AWS:

Tipe Record Name / Host Value / Target (IP AWS) TTL
A @ (atau namadomain.com) 3.81.83.137 Auto / 3600
A (atau CNAME) www 3.81.83.137 (atau namadomain.com jika CNAME) Auto / 3600

Checklist Deployment Akhir:

  • Mengunggah / melakukan clone file website ke direktori web server.
  • Memastikan akses web melalui IP Publik / propagasi DNS berjalan lancar di browser.
  • Mengaktifkan HTTPS / mengamankan konfigurasi port web server.

Fase 6: Manajemen, Monitoring & Backup

Catat Metrik Server Saat Ini (AWS CloudWatch):

  • Rata-rata CPU Utilization: 1.2% - 5.0% (Kondisi normal / idle saat melayani web statis)
  • Status Check Failed: 0 (3/3 checks passed - Sistem dan instance berjalan normal)

Langkah Backup (Snapshot) Volume EBS:

  1. Buka menu Volumes di konsol EC2.
  2. Pilih Volume yang terhubung dengan instance server-windows (i-07887d79962e315dd).
  3. Klik Actions > Create Snapshot.
  4. Beri deskripsi backup dan klik Create Snapshot untuk menyimpan.
